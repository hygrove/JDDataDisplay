# 归档区放在源表目录之外，保留 60 天

归档文件移到源表目录**之外**的归档区，按整理日期分子目录，并配一份清单记录每个文件的原路径、归档路径与判定理由；超过 60 天视为可清理。放在目录之外，是因为批处理的文件枚举虽然是非递归 glob、目录内的子目录今天不会被读到，但依赖这一隐式前提很脆弱——枚举方式一旦改成递归（`rglob`），归档就会被重新吸回数据管线，而且这种失败是静默的。保留 60 天而非永久，是因为整理的目的就是让源目录保持可读，而归档的唯一价值是"万一误归档还能捞回来"，60 天足够覆盖误判被发现的时间。

## Consequences

回滚是跨目录操作，且必须依赖清单——清单若丢失，对应那批归档等同于不可恢复。60 天的清理必须区分"归档"与"隔离"：隔离区里的文件是在等人判断的，不应被清理策略连带处理掉。
