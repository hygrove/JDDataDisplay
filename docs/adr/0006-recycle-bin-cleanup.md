# 归档超期 60 天后自动移入系统回收站

到达 60 天的归档文件，由整理器自动移入**系统回收站**，不做硬删除。选择回收站而不是"只在报告里列出待清理"，是因为这条清理会无人值守地持续跑，需要一个不依赖人在场的兜底层；选回收站而不是硬删，是因为硬删不可逆。

选择自动执行而非"等人手动清理"，理由是源数据的性质：这些滚动窗口表是从商家后台**可以重新下载**的产物，60 天前的数据早已被后续下载覆盖，继续占着磁盘的边际价值低于自动清理的收益——被清掉的东西不是这世上唯一的一份。

## Consequences

回收站有容量上限，超出后最旧的条目会被**永久删除**。批量清理因此可能把回收站里更早的、与归档无关的文件一并挤出——这是本决策唯一波及归档区之外的副作用，必须写进报告提示，不能默默发生。回收站 API 依赖本地卷：若项目位于网络驱动器或回收站不可用的卷上，清理自动降级为"仅在报告里列出"，绝不静默失败。隔离区不参与这条清理。
